# SAFOD AWD clean analysis

## Authoritative notebooks by workflow

`AWD_results_dashboard.ipynb` is the authoritative AWD analysis notebook. Its
internal Markdown version cell is the version record; the current version is
**v25**. Automated AWD jobs may write status and proposed-update Markdown
files, but they must not create or modify another AWD notebook. The v15
dashboard promotes the hierarchical Nano repeatability analysis, the completed
Deep localized validation/negative conversion-depth search, the conditional
Deep coordinate-registration/forward consistency test, the
source-history/tidal-timescale delay regression, and exploratory/physical-phase
CCA controls with serial-dependence-aware nulls.

`Ambient_FK_QC_workflow.ipynb` is the single authoritative ambient-noise F--K
quality-control notebook. It is generated reproducibly by
`build_ambient_fk_qc_notebook.py`, documents the Lellouch et al. (2019)
reproduction attempt and all project-specific extensions, and supersedes the
earlier `Ambient_FK_QC_workflow_v1.ipynb` draft.

Rebuild and execute that notebook from the repository's `notebooks/` directory:

```bash
python3 awd_clean/build_ambient_fk_qc_notebook.py
jupyter nbconvert --to notebook --execute --inplace \
  awd_clean/Ambient_FK_QC_workflow.ipynb \
  --ExecutePreprocessor.kernel_name=das \
  --ExecutePreprocessor.timeout=900
```

The system Python builds the notebook because it provides `nbformat`; the
registered `das` kernel executes the scientific cells.

This directory is an AWD-only replacement workflow. It does not use
`SAFOD_ActiveSrc_ShotLocs&Times_20260617.csv`; those shots are a separate
experiment.

Working geometry assumptions:

- the accelerated weight drop (AWD) remained fixed for the survey;
- its horizontal offset from the Nano wellhead was approximately 15 m;
- channel coordinate is distance along fiber, not calibrated true depth;
- phase names are withheld until moveout and frequency behavior validate them.
- Deep `StartLocusIndex` and hairpin coordinates are interrogator coordinates, not measured depth; no fiber-to-depth transform or borehole logs are currently available.
- The burst-delay tidal-timescale branch uses cumulative drops and signal RMS as source-history/coupling proxies; it is a candidate pattern, not a physically phased tide detection; the UTC-phased Sun/Moon potential control is weaker and does not support opening/closing.
- The phase-free CCA finds a full-sample association but fails the serial block null/held-out stability check. The physical-phase CCA gives r=0.366, row p=0.116, block p=0.263, and remains a negative control rather than a tidal detection.

The first product is `awd_manifest.csv`, generated by `build_manifest.py` from
the GPS times and the actual Nano/Deep file coverage. Bursts are never silently
truncated to an expected count.

The v19 audit documents why the earlier ambient-noise cross-correlation attempt did not reproduce Lellouch et al. (2019): the acquisition, virtual-source geometry, stacking design, and correlation scaling were not matched to the published experiment. It defines a controlled two-geometry transfer test and explicitly classifies the prior result as inconclusive rather than as a failure of ambient interferometry.

The v20 dashboard adds the controlled Lellouch-style transfer pilot. Three independent 10-file stacks (30 segments total) used the published top/50-m geometries and bounded pairwise normalization. The 3.2-km/s score was -0.00266, the weak maximum was 0.00388 near 1.65 km/s, and a receiver-position permutation null gave p=0.875. This is a negative transfer pilot, not a definitive rejection of the 2017 result.

The v21 dashboard extends the corrected baseline to seven independent 10-file chunks (70 segments, approximately 70 minutes). The 3.2-km/s score is -0.00321; the weak maximum is 0.00481 near 1.40 km/s; receiver-position permutation p=0.561. It also specifies a non-circular F--K extension using fixed 5-20 Hz, 2.5-4.5 km/s signed-wavenumber wedges and held-out validation.

The v22 dashboard adds an exploratory signed-wavenumber F-K branch. A fixed 5-20 Hz, 2.5-4.5 km/s positive wedge gives a 3.2-km/s score of 0.01257 in 10 segments, with a maximum near 3.78 km/s. This is not confirmatory because the mask retains that velocity interval by construction; signed, complementary, permutation, and held-out controls remain required.

The v23 dashboard promotes the signed F-K control result: negative-wavenumber branch peak 3.075 km/s, 3.2-km/s score 0.2952, and receiver-position permutation p=0.0005 after combining three independent 10-file chunks. Positive and complementary wedges fail their controls. This is preliminary because the fixed wedge contains the target velocity interval; held-out days and wedge-sensitivity tests remain required.

The v24 clarification corrects the elapsed-time labels: each HDF5 segment is 30,000 samples at 500 Hz (60 s), so 10 segments are approximately 10 min, 30 are 30 min, and 70 are 70 min. The results are unchanged.

The v25 dashboard extends the frozen negative F-K wedge to seven independent 10-file chunks (70 segments, approximately 70 minutes). Peak 3.075 km/s, score at 3.2 km/s 0.2947, permutation p=0.0002; all seven chunk scores are positive. This is a stable 70-minute selected observable, not yet a complete-day reproduction.
