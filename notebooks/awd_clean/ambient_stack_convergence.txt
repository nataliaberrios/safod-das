  2024-12-20, hourly chunks, both branches
  The quantity to read is DETECTABILITY = score / its own null 95th.
  A raw score can rise merely because a repeatable contaminant
  accumulates; detectability rises only if the observation outruns what
  permuted receiver order produces from the same data.

  baseline (no common-mode removal)  detectability exponent +0.042 -> FLAT: more data does not help
  common-mode removed                detectability exponent +0.019 -> FLAT: more data does not help

  NEITHER branch shows sqrt(N) growth in detectability. This is the
  quantitative answer to 'more data should win': it should, and it
  does not. Averaging suppresses INCOHERENT noise as 1/sqrt(N), so
  detectability grows as sqrt(N) ONLY if there is a coherent arrival
  to accumulate. A flat detectability curve means either the limiting
  contaminant averages exactly as the signal would -- i.e. it repeats
  window to window -- or there is no arrival to accumulate. The
  common-mode-removed branch discriminates: with the repeatable
  pattern suppressed (pedestal -0.219 at full stack), a flat curve
  leaves absence as the explanation.

  Consistent with Behm (2016), where 30 s sufficed under adequate
  illumination, and with the four-day stack (p = 0.9184) sitting
  further from significance than the best single day (p = 0.1345).

  LIMITS: one day, hourly granularity, so this measures within-day
  convergence; the four-day result covers the across-day case. The null
  is receiver-order permutation, which does not contain any pre-
  correlation operator.
