# Reproducing every number in DOCUMENT.md

Dependency-ordered map from each claim to the script that produced it, following
the convention of `awd_clean/manuscript/REPRODUCE.md`. `FIGURE_NUMBERS.txt` is
generated by `make_figures.py` and lists every plotted value with its source
product; it is the machine-checked half of this file.

All paths are relative to `notebooks/awd_clean/`. Environment: `ml gcc/12.4.0`,
`conda activate das`, or the absolute interpreter
`/home/users/nberrios/miniconda3/envs/das/bin/python`. All jobs go to `-p serc`.

## Build order

```bash
cd notebooks/awd_clean/fig7c_negative
python make_figures.py      # or: sbatch figs_job.sh
python3 assemble.py         # sections/*.md -> DOCUMENT.md; never edit DOCUMENT.md
```

`assemble.py` fails if a figure is referenced without a caption, if a caption is
never referenced, or if a referenced PNG is missing. `make_figures.py` fails if
any input product is absent rather than drawing a partial figure.

## Section 4.1 -- implementation validation

| claim | value | script | product |
|---|---|---|---|
| picks from Lellouch's released 7d traces | 2,416 m/s at 50 m to 4,357 m/s at 700 m | `ambient_lellouch_fig7d_profile.py` | `.txt` lines 29-43 |
| depth-velocity correlation on those picks | r = 0.948 | same | `.txt` "fit r" |
| same picker on our data | 1 of 14 depths finite | same | `.npz` `v_median` |

**Read this before quoting r = 0.948.** It is `np.corrcoef(lel_z, lel_v)` at
`ambient_lellouch_fig7d_profile.py:213` -- the correlation between depth and the
velocities our picker returns from *his* traces. It is **not** agreement with his
published Figure 9 curve, which is not digitised in this repository. The `.npz`
key `r` is a *different* quantity: the velocity-depth trend of **our** data,
r = -0.445. Confusing the two produced an overstatement in an earlier draft and in
this project's planning document.

## Data

`/oak/stanford/groups/ettore88/data/SAFOD/SAFODAS1-harddrive-transfer/`, manifest
`SAFOD_2024_2025.csv`, 377,680 continuous 60 s records, 2024-05-21 to 2025-05-06.
Lellouch's release staged at `/scratch/users/nberrios/lellouch2017/` (`M1p33`,
`M2p46`, `README.md`); correlograms in `awd_clean/lellouch_traces/`.

**Never read 2024-25 data through `DASutils.readFile_HDF` for any k = 0 or
common-mode measurement.** Its `median=True` default subtracts the per-sample
median across channels and removes the quantity under test. Every script here
uses `h5py` directly. This is the confound that invalidated
`faultzone/repeaters/cross_epoch_noise_floor.py` and it also rules out the 206
cached events in `faultzone/repeaters/cache_all/` for such measurements.
